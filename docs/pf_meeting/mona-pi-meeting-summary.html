Flow Matching 기반 VLA 아키텍처 설계
π0 논문 기반 Conditional Flow Matching(CFM) 구조 확정. PaliGemma 3B backbone + FlowMatchingHead. 손실: L = ‖v_θ − (x₁ − x₀)‖²

HDF5 커스텀 데이터셋 파이프라인 구축
Serbot2 실주행 데이터를 HDF5로 저장하는 수집·전처리 파이프라인 완성. 에피소드 단위 구조 (이미지 + 액션 벡터 3-DOF).
확인
초기 모델 학습 및 오프라인 검증
116 에피소드 초기 학습, val_loss 수렴 확인. Flow Matching이 모바일 내비게이션에 적용 가능함을 기술적으로 검증 완료.

평가 설계

Closed-Loop 평가 기준 확정

GT 이미지 (step별)

FPE / TLD 계산
FPE — Final Position Error
에피소드 종료 시 추정 위치 ↔ GT 목표 위치 간 유클리드 거리.
성공 기준: FPE < 0.3m
TLD — Trajectory Length Deviation
모델 이동 거리 / GT 경로 거리. 1.0 = 동일.
성공 기준: 0.7 ≤ TLD ≤ 1.5
1.5 초과=지나침, 0.7 미만=조기 정지
협의 결론: FPE + TLD 두 지표가 이후 모든 Ablation 실험(M1–M7)의 공통 성공 기준으로 채택. 정형 9종(Regular)과 add_free 두 세트에 각각 측정.
