FPE — Final Position Error
에피소드 종료 시 추정 위치와 GT 목표 위치 간 유클리드 거리.
성공 기준: FPE < 0.3m
TLD — Trajectory Length Deviation
모델이 이동한 총 거리 / GT 경로 총 거리. 1.0 = 동일한 거리.
성공 기준: 0.7 ≤ TLD ≤ 1.5
1.5 초과 = 지나침, 0.7 미만 = 조기 정지
협의 결론: 이 두 지표(FPE + TLD)가 이후 모든 Ablation 실험(M1–M7)의 공통 성공 기준으로 채택됨. 정형 9종 경로(Regular)와 add_free 시나리오 두 세트에 대해 각각 측정.
