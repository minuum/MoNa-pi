# [회의록 모음] MoNa-pi 프로젝트 지도교수 미팅 — 2026년 1학기

**참석자 공통**: 지도교수님, 팀장 임현우

---

## 2026년 5월 8일

**주요 내용**

- Flow Matching 기반 VLA 아키텍처 설계와 커스텀 데이터셋(HDF5) 파이프라인 구축을 성공적으로 완료
- 초기 모델 학습 및 오프라인 검증을 통해 기술적 타당성을 확인
- 향후 데이터 보강(누락 에피소드 수집, 증강 기법 적용)을 통해 모델 일반화 성능을 최적화하고, 최종적으로 실제 로봇 환경에서 50Hz 실시간 자율 주행 통합 테스트를 완수하기로 협의

---

## 2026년 5월 21일

**주요 내용**

- 학습 데이터셋을 116 에피소드에서 244 에피소드(v5)로 확장하고, Random Crop 및 Classifier-Free Guidance(CFG) 기반 데이터 증강 기법을 추가 적용하여 모델 일반화 성능 향상 기반 마련
- FP16 학습 시 NaN 그라디언트 발생 문제를 BF16 전면 전환으로 해결하여 학습 안정성 확보, val_loss 0.07대 수준까지 수렴 확인
- 언어 명령 기반 의도 주입을 위한 IntentPrefixInjector 설계 완료(9-class 태그: [FORWARD], [STRAFE_LEFT] 등), 학습·추론 일관성 유지 방침 확정
- 오프라인 Closed-Loop 평가 프레임워크 설계 완료 및 성공 기준 정의(최종 위치 오차 FPE < 0.3m AND 이동 거리 비율 TLD ∈ [0.7, 1.5]) — 이후 Ablation 실험의 공통 지표로 사용하기로 협의

## 2026년 5월 27일

**주요 내용**

- Ablation 실험 매트릭스(M1–M7) 설계 최종 확정: backbone 종류(base PaliGemma / lerobot 사전학습), action expert 구조(FlowHead / GemmaExpert), 데이터 증강 유무, 데이터 크기(116 vs. 244 에피소드), LoRA(rank=16), ODE steps(3/5/10) 등 6개 요인 비교
- GemmaActionExpert(실제 π0 아키텍처 — Gemma 트랜스포머 레이어 기반 VLM+action 통합 self-attention) 구현 완료 및 lerobot π0 사전학습 가중치 추출 파이프라인 수립
- Serbot2 온보드 배포 계획 확정: INT8 양자화(BF16 ~6GB → INT8 ~3GB), 24GB 스왑, FastAPI 추론 서버(포트 8082) 구성 방안 협의
- 6/4 캡스톤 경진대회 발표 리허설 진행 — 발표 흐름(기획 의도 → 시스템 아키텍처 → 실험 결과 → 기여) 및 시간 배분(10분 내) 피드백 수렴, 정량적 실험 결과 중심 구성으로 수정하기로 합의
