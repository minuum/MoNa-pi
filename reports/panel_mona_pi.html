1 문제 정의
❌ 기존 VLA의 한계
  • 로봇 팔(Manipulation) 중심 설계 — 모바일 내비게이션 미지원
  • 이산 분류(3~9 클래스) → 연속적 이동 제어 불가
  • Diffusion Policy: 100+ ODE steps → 느린 추론
  • 언어 이해 능력 미탑재 또는 제한적
✅ MoNa-pi의 접근
  • π0(Flow Matching VLA)를 모바일 도메인으로 전이
  • 연속 3-DOF 속도 벡터 직접 출력
  • 5-step ODE로 고속 추론 (50Hz 실시간 가능)
  • PaliGemma 3B VLM — 자연어 명령 직접 이해

6 핵심 기술

① Conditional Flow Matching (CFM)

L = ‖ v_θ(x_t, t, c) − (x₁ − x₀) ‖²

x₀ ~ N(0,I) (노이즈), x₁ (타겟 액션), t ~ U[0,1]
5-step Heun ODE로 고속 역방향 적분 → 액션 생성

② PaliGemma 3B Backbone (BF16)

  • SigLIP 비전 인코더 → 이미지 패치 임베딩
  • Gemma-2B 언어 모델 → 언어-비전 통합 표현
  • FP16 NaN 문제 → BF16 전면 전환으로 해결

③ IntentPrefixInjector

9-class 의도 태그 자동 주입: [FORWARD] [STRAFE_LEFT] [ROT_RIGHT] 등
학습-추론 간 언어 분포 일관성 확보

④ Action Chunking + Receding Horizon

  • 한 번에 10스텝 액션 청크 생성
  • 버퍼 50% 소진 시 재계획 (10Hz 제어 루프)
  • 지연 없이 50Hz 연속 제어 가능
