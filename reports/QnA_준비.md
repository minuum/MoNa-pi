| 왜 π0 아키텍처를 선택했나요? | SigLIP(시각)+Gemma(언어)+Flow Matching(연속제어) 세 요소가 이미 검증됨. 여기에 도메인 이전만 추가 | 🟢 |

### S4 — 본 연구의 접근·목표

| 예상 질문 | 핵심 답변 | 위험도 |
|---|---|---|
| Flow Matching이 뭔가요? | 노이즈 → 행동으로의 **직선 경로**를 학습. Diffusion의 1000+스텝 대신 **5스텝 ODE**로 실시간 가능 | 🟡 |
| Diffusion Policy 대비 왜 더 빠른가요? | Diffusion은 SDE(확률미분방정식), FM은 ODE(결정론적). ODE는 단계 수가 적어도 수렴 → 5스텝으로 250ms 이내 달성 | 🔴 |
| /1 Domain /2 Action /3 Feasibility가 무슨 뜻인가요? | 세 핵심 연구 목표: ① 도메인 이전, ② 연속 행동 생성, ③ 실배포 가능성 검증 | 🟢 |
| 왜 Omni-wheel인가요? | 3-DOF(linear_x, linear_y, angular_z) 전방향 이동 가능 → 다양한 경로 패턴 실험 가능 | 🟢 |

### S5 — 연구과정 (개발과정)

| 예상 질문 | 핵심 답변 | 위험도 |
|---|---|---|
| PaliGemma 2가 아닌가요? | **PaliGemma 3B**입니다. 슬라이드 로고가 2로 표기된 건 오류 | 🟡 |
| Gemma Expert가 뭔가요? | base PaliGemma 위에 **4-layer Cross-Attention Action Expert**를 추가한 π0-faithful 아키텍처 | 🟡 |
| LoRA는 왜 아직 학습중인가요? | base/Expert 모델이 이미 연구 목표 달성. LoRA는 **파라미터 효율성 비교** 추가 실험 | 🟢 |
| CL SR 100% 달성이 정확히 무슨 뜻인가요? | **Closed-Loop** 평가: 모델이 순서대로 목표를 추론→행동 반복, 최종 목표 위치 **0.3m 이내** 도달 여부 | 🟡 |
| 역할 분담에서 각자 구체적으로 뭘 했나요? | 이민우: 모델 아키텍처·학습·검증 / 오은석: Serbot2 인프라·ROS2 / 정재연: 데이터셋 수집 파이프라인 | 🟢 |

### S6 — 시스템 아키텍처

| 예상 질문 | 핵심 답변 | 위험도 |
|---|---|---|
| 왜 하필 PaliGemma인가요? | SigLIP(시각인코더)+Gemma-2B(언어)가 이미 통합된 VLM. 멀티모달 컨텍스트를 2048차원으로 압축 가능 | 🟡 |
| 4Hz로 충분한가요? | **Action Chunking** 덕분에 가능. 4Hz로 10스텝 청크 생성 → **50Hz 로컬 버퍼 실행**. VLA가 추론하는 동안 이전 청크 계속 실행 | 🔴 |
| BF16을 쓰는 이유는? | FP16은 지수 범위가 좁아 **대형 gradient에서 오버플로** 발생 → 실험으로 FPE 3.1배 증가 확인. BF16은 FP32와 같은 지수 범위 유지 | 🔴 |
| 8프레임 왜 씁니까? | 모바일 로봇은 시간에 따른 **움직임의 연속성** 파악이 중요. 8프레임(0.8초 윈도우)으로 방향 전환 의도 파악 | 🟡 |
| 추론 서버가 GX10인데 Serbot2와 어떻게 연결되나요? | GX10 FastAPI `/predict` → (B,10,3) 액션 청크 반환 → Serbot2 Action Buffer → 50Hz 실행 | 🟢 |
| Action Expert의 Cross-Attention은 무엇을 어떻게 연결하나요? | 언어+시각 컨텍스트(2048dim)를 **key/value**, 노이즈 행동(x_t)을 **query**로 Cross-Attention. 조건부로 속도 벡터 필드 예측 | 🔴 |

### S7 — 실험 환경

| 예상 질문 | 핵심 답변 | 위험도 |
|---|---|---|
| 왜 2m×2m밖에 안 되나요? | 실내 공간 제약. 중요한 건 **9가지 경로 패턴 재현 가능 여부**이며 해당 공간에서 충분히 검증 | 🟢 |
| 카테고리당 15-30 에피소드는 너무 적은 거 아닌가요? | **적은 데이터로 최적화 가능한 파이프라인 제시**가 기여 중 하나. 정형 경로는 이 수준에서 100% 달성 확인 | 🟡 |
| Threshold 0.3m 기준은 어떻게 정했나요? | 목표 오브젝트(바구니) 크기 기준. 0.3m 이내면 실제 목표에 도달했다고 판단 가능한 거리 | 🟢 |
| 왜 Gray Basket인가요? | 시각적으로 뚜렷한 단일 목표물. 카메라 뷰에서 일관되게 인식 가능 | 🟢 |
| 9가지 카테고리를 선정한 기준은? | 시작 위치(Center/Left/Right) × 이동 방향(Straight/Left/Right) = 3×3. 모바일 로봇의 기본 내비게이션 시나리오 전체 커버 | 🟢 |

### S8 — 실험 결과 ⚠️ 질문 집중 예상

| 예상 질문 | 핵심 답변 | 위험도 |
|---|---|---|
| 정형 경로 100%면 그냥 외운 거 아닌가요? | 에피소드 **train/test 분리** + **Instruction Pool 15개 paraphrase** 무작위 선택. 학습에 없던 표현에도 대응 | 🔴 |
| 비정형 경로 13%는 너무 낮지 않나요? | 비정형(center_left, left_right)은 **시각적 모호성**이 핵심 문제 — 시작 위치와 목표 위치가 카메라상 구분 어려움. 현재 한계로 명시, 데이터 추가 수집이 후속 계획 | 🔴 |
| Closed-Loop 평가가 실제 로봇 테스트인가요? | 실제 모델 추론을 **순차적으로 반복**하는 방식. 물리적 주행 검증은 Serbot2 배포(D10-11) 예정 | 🔴 |
| FPE가 뭔가요? | **Final Position Error** — 목표 위치에서 최종 예측 위치까지의 거리(m). 낮을수록 정확 | 🟢 |
| Gemma Expert가 base보다 SR은 높은데 FPE는 오히려 높네요? | 75.5% vs 73.6%로 근소한 차이. FPE 차이(0.070 vs 0.073)도 통계적으로 유의하지 않은 수준. 현재는 **base PaliGemma도 충분한 성능** | 🟡 |
| 38/38이랑 39/53 — 분모가 왜 다른가요? | 38은 **정형 9종** 카테고리 테스트 에피소드 수, 53은 **비정형 포함 전체** 테스트 에피소드 수 | 🟡 |

## 🔴 핵심 트랩 질문 (반드시 준비)

### T1 — "실로봇 테스트 없이 결과라고 할 수 있나요?"
> "네, Closed-Loop 평가는 실제 모델 추론 기반이지만 물리적 주행은 미완료입니다. 이걸 한계로 명시했고 Serbot2 실배포가 다음 단계입니다. 현재 GX10에서 243ms 추론 검증과 Serbot2 VRAM 호환은 확인됐습니다."

### T2 — "100%면 과적합 아닌가요?"
> "Train/test 에피소드 분리 + 15개 paraphrase 무작위 선택으로 일반화를 검증했습니다. 다만 비정형 경로 13%가 보여주듯, 일반화 한계는 존재하며 이를 솔직히 결론에 포함시켰습니다."

### T3 — "Flow Matching이 왜 Diffusion보다 낫다는 증거가 있나요?"
> "직접 비교는 안 했지만, 추론 속도에서 결과로 증명됩니다. Diffusion Policy는 1000+ 스텝 필요 → 실시간 불가. FM은 5스텝 ODE로 243ms 달성 → 4Hz 예산 내 실시간 제어 가능."

### T4 — "PaliGemma가 2인지 3B인지 모르는 거 아닌가요?" (슬라이드 오류 관련)
> "사용한 모델은 PaliGemma 3B입니다. 슬라이드 로고 표기가 잘못됐습니다. SigLIP SO400M + Gemma-2B 구성의 3B 파라미터 모델을 BF16으로 파인튜닝했습니다."

### T5 — "데이터가 244 에피소드뿐인데 충분한가요?"
> "정형 경로에서 100% 달성이 증명하듯, 도메인이 좁고 명확하면 적은 데이터로도 가능합니다. 이게 저희 연구 기여 중 하나입니다 — 적은 데이터로 최적화 가능한 파이프라인 제시."

## 용어 빠른 참조

| 용어 | 한 줄 설명 |
|---|---|
| CL SR | Closed-Loop Success Rate — 순차 추론으로 목표 도달 성공률 |
| FPE | Final Position Error — 목표 위치 대비 최종 오차 (m) |
| Action Chunking | 미래 10스텝 동시 예측, 버퍼에 저장 후 50Hz 실행 |
| BF16 | Brain Float 16 — FP32와 같은 지수 범위, Gradient 안정 |
| Flow Matching | 노이즈→행동 직선 경로 학습 (ODE 기반, 5스텝) |
| Closed-Loop | 모델이 매 스텝 추론하며 다음 행동 결정하는 순환 평가 |
| Instruction Pool | 카테고리당 15개 paraphrase, 매 스텝 무작위 선택 |
| Gemma Expert | PaliGemma 위에 Cross-Attention Action Expert 추가한 모델 |
| 정형 경로 | 9가지 카테고리 중 학습 데이터와 유사한 패턴 |
| 비정형 경로 | center_left, left_right 등 시각 모호성 높은 카테고리 |
